    Choose a surface, tune its detail, and export your settings as a JSON file.

  2. 02

    Install the toolkit

    In Blender: Edit → Preferences → Add-ons → Install from Disk. Choose astra.zip and enable ASTRA.

  3. 03

    Make it yours

    Open the 3D View sidebar → ASTRA. Import your settings, apply to a mesh, or generate the demo scene.

Compatibility & preview notes +

ASTRA 0.1 targets Blender 5.2.2. The browser uses Three.js and a procedural approximation; it is not a Blender render. The add-on uses Principled BSDF shaders and object coordinates. Use real-world dimensions and unit object scale for consistent texture density. Glass requires a closed mesh with thickness. The initial toolkit includes six materials, four lighting rigs, render presets, settings import, a PBR map importer, and scene validation. True displacement and geometry-aware edge wear are not implemented.
