Compatibility & preview notes +

ASTRA 0.2 targets Blender 5.2.2. The browser uses Three.js and a procedural approximation; it is not a Blender render. The add-on uses Principled BSDF shaders and object coordinates. Use real-world dimensions and unit object scale for consistent texture density. Glass requires a closed mesh with thickness. The initial toolkit includes six materials, four lighting rigs, render presets, settings import, a PBR map importer, and scene validation. The rooftop is a fictional, procedurally constructed set inspired by dense urban roofscapes; it is not a survey, scan, or reconstruction of a real address. Browser reflections are static captures, and haze is a depth approximation. True displacement and geometry-aware edge wear are not implemented.
